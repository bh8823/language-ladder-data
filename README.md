# Language Ladder — video library data

Public data files read by the Language Ladder app (served with GitHub Pages):
`lib/` and `kw/` (scored videos and their key words, by language; `library.json` until 2026-11-15), `thumbs/`,
`texts/` (subtitles for summaries), `audio/` (recorded sentences for older videos and made-up examples, still played by the
app), and `pipeline/` (the scorer's own state, read by the library update, not by the app).
Generated by the scoring pipeline in the app repo; don't edit by hand.
